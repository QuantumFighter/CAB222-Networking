# S1-05 Navigate all six challenges and complete the unit

Type: feature. Suggested effort: 1.5 hours. Dependencies: S1-04.

As a learner, I want to see my progress and finish the unit so that I know which questions I have completed.

## Acceptance criteria

- [ ] Selecting a lesson shows its first unanswered question, or a completed question for review if both are complete.
- [ ] Next advances through the questions in lesson order after the current question is correct. Selecting lessons remains available for review.
- [ ] Changing questions clears the previous unanswered selection and feedback. Revisiting a completed question shows its saved correct answer and explanation.
- [ ] The window shows `Questions completed: N/6`. Incorrect attempts do not increase N; correcting a question increases N once.
- [ ] Repeated submissions and lesson changes cannot inflate N. Completion of all six unique question IDs shows `Week 1 foundations complete`.
- [ ] A New session control clears answers, feedback and completion and returns to the first lesson and question. Relaunching also begins fresh.
- [ ] Automated tests verify wrong-then-correct completion, repeat submissions, all-six completion and session reset.

## Scope

Use memory for session state. Do not add a database, account, saved progress or XP in this issue.

Suggested branch: `feature/s1-05-unit-progress`.

## Evidence for review

Demonstrate all-six completion, revisit one completed question, and start a new session. Record the progress test results.
