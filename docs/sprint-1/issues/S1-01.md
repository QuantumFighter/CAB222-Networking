# S1-01 Set up a runnable Java desktop project in IntelliJ

Type: technical task. Suggested effort: 1.5 hours. Dependencies: none.

Enable a reliable build and launch before implementing the learning interface.

## Acceptance criteria

- [ ] The existing repository opens as one Maven project in IntelliJ, with `src/main/java`, `src/main/resources` and `src/test/java` recognised.
- [ ] The README records the actual JDK used and steps to build and launch. IntelliJ and Maven use compatible JDK settings.
- [ ] Running the application entry point opens a Swing window titled `CAB222 Network Academy` and closing it ends the application.
- [ ] Swing UI construction runs on the event dispatch thread.
- [ ] A clean Maven build succeeds. Generated `target/` and `out/` files and personal IDE workspace settings are ignored by Git.

## Implementation notes

Add a `pom.xml` to the existing project. Use the configured OpenJDK 26 if available; verify the installation first. Add the JUnit dependency for the later grading and progress tests. A blank titled window is sufficient for this task.

Suggested branch: `chore/s1-01-project-setup`.
