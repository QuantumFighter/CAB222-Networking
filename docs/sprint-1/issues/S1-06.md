# S1-06 Review the working app and demonstrate Week 1 learning

Type: validation and learning task. Suggested effort: 1 hour. Dependencies: S1-05.

As the learner and developer, I want to check both the application and my understanding so that the sprint delivers useful learning.

## Acceptance criteria

- [ ] A clean build and all grading and progress tests pass, with the result recorded in the PR.
- [ ] A manual walkthrough covers lesson selection, long text, an empty submission, incorrect feedback, retry, all-six completion, repeated clicks, question switching and session reset.
- [ ] The README gives reproducible IntelliJ build and run instructions, describes the three lessons and states that session progress resets.
- [ ] Without notes, explain a switch versus a router, list all seven OSI layers, and describe the explicit TCP encapsulation example. Record any gaps as follow-up study tasks.
- [ ] Try a fresh scenario, such as connecting two office IP networks, and justify the device and relevant layer using your own reasoning.
- [ ] Record actual effort, one useful practice, one obstacle and one change to try next sprint. File remaining defects and Week 1 content gaps as backlog issues.

## Demo sequence

Open app, read a lesson, make a deliberate incorrect selection, explain its feedback, correct it, complete the remaining challenges, revisit one answer and reset the session.

Suggested branch: `docs/s1-06-review`.

## Definition of completion

Application checks and the learning review both matter. Repeating the stored answer text alone does not demonstrate that you can apply the concept.
