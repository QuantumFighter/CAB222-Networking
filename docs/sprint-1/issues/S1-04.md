# S1-04 Answer a challenge and receive explanatory feedback

Type: feature. Suggested effort: 2 hours. Dependencies: S1-03.

As a learner, I want to submit an answer and understand the feedback so that I can correct a misconception.

## Acceptance criteria

- [ ] The challenge panel displays the current question and four labelled radio-button options. Only one option can be selected.
- [ ] Submitting without a selection displays `Choose an answer first` and does not grade or complete the question.
- [ ] Submitting an incorrect option displays `Not yet` and that option's explanation, and permits another attempt.
- [ ] Submitting the correct option displays `Correct` with an explanation and completes the question once.
- [ ] A completed question keeps its correct answer and explanation visible; further submissions cannot award additional completion.
- [ ] Feedback includes text rather than relying on colour alone.
- [ ] Automated tests cover correct, incorrect and empty selections. Grading can be tested without opening a Swing window.

## Implementation notes

Use option IDs when checking answers. Keep the answer check separate from the UI and have the UI display its result. This issue should support a complete first-lesson demonstration before unit navigation is finished.

Suggested branch: `feature/s1-04-answer-feedback`.

## Evidence for review

Show an incorrect attempt followed by a correct attempt. Record the test command and outcome in the PR.
