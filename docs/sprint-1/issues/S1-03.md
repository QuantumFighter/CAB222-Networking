# S1-03 Display a Week 1 lesson in the desktop interface

Type: feature. Suggested effort: 1.5 hours. Dependencies: S1-01 and S1-02.

As a learner, I want to select and read a lesson so that I can understand a concept before answering a challenge.

## Acceptance criteria

- [ ] The window lists the three Week 1 lesson titles, and the first lesson is selected on launch.
- [ ] Selecting a lesson shows its title, learning outcome, complete text and source reference.
- [ ] Long lesson text scrolls and wraps without disappearing outside the window. Controls remain usable at 1100 by 750 pixels.
- [ ] A labelled challenge panel is visible beside the lesson. It can remain a placeholder until S1-04.
- [ ] The same reader components display all three lessons; lesson text is not embedded in button handlers.

## Implementation notes

A lesson list, a scrollable read-only text component and a challenge panel are enough. Aim for readable spacing before adding decoration.

Suggested branch: `feature/s1-03-lesson-reader`.

## Evidence for review

Manually select each lesson and resize the window. Attach a screenshot or brief demonstration to the pull request.
