# CAB222-Networking


## Development setup

- JDK: OpenJDK 26.0.1
- Build system: Maven
- Desktop interface: Swing

### Build

Open the project in IntelliJ and load pom.xml as a Maven project.
Set the Maven Runner JRE to Project JDK.

In the Maven tool window, run clean, then verify.

### Run

Open App.java and run its main method.

A window titled CAB222 Network Academy should appear.
Closing the window ends the application.
